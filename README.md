# Skill.Nova

Skill.Nova is a responsive course-platform landing page with original branding, career-focused course cards, mentor-guided learning paths, a counselling form, FAQs and an interactive support chatbot.

## Features

- Responsive desktop, tablet and mobile layout
- Original Skill.Nova logo and blue–violet–mint visual system
- Course cards and guided learning-path sections
- Career roadmap, learner outcome and testimonial sections
- Interactive counselling form with success state
- Expandable FAQ accordion
- Scripted Nova Guide chatbot with quick replies
- Placeholder Instagram, WhatsApp and email configuration

## Run locally

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
```

## Contact setup

Update the `CONTACTS` object near the top of `src/main.jsx` after the final email, Instagram URL and WhatsApp link are available.
